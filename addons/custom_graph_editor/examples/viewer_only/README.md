# Viewer Only Example

This example demonstrates using [`CGEGraphViewer`](../../graph_viewer.gd) standalone, with no
`CGEGraphEditor` at all.

It has no input, this is just a raw example. The main script could be extended to react to some signals of the `CGEGraphViewer`.

## What's Included
- `viewer_only_demo.tscn` / `viewer_only_demo.gd`
    - A scene containing only a `CGEGraphViewer` (no editor)
  - Builds a small hardcoded `CGEGraph`
  - No editor, only a graph navigation

# Pretty Viewer Example

A fancier standalone [`CGEGraphViewer`](../../graph_viewer.gd) demo than `examples/viewer_only` to display more capabilities on graph preview.

## What's Included
- `pretty_viewer_demo.tscn` / `pretty_viewer_demo.gd`
    - A marker `Control` that continuously travels around the ring
      following correctly even if the target node is moving)
    - One node moves up and down with a looping `Tween`
